## Findings

### HIVE-SEC-2026-001 — Authenticated users can exhaust shared artifact storage

- Severity and rationale: Medium. An authenticated user can repeatedly upload individually valid media files. Because uploads receive unique names and no aggregate quota or file-count limit is enforced, persistent shared storage can be exhausted, affecting application availability.
- Confidence: High
- Status: Open
- Location: `apps/api/src/artifacts.ts:201-221`; `apps/api/src/artifactStore.ts:48-75`; authenticated API mount at `apps/api/src/index.ts:33`
- Evidence: The upload handler limits each request body to 50 MB and validates media type and optional workflow ownership before writing. The storage layer enforces per-file limits (10 MB images, 50 MB video, 25 MB audio), checks file signatures, and saves each accepted upload under a fresh UUID. No per-user aggregate bytes quota, maximum file count, or shared storage quota check is present before persistence. The endpoint requires authentication; this finding does not describe anonymous access.
- Impact and preconditions: A valid Hive account and repeated accepted uploads are required. Accumulated uploads can fill the artifact volume and prevent subsequent uploads or other operations that depend on that storage.
- Remediation: Enforce per-user and instance-wide aggregate storage limits and file-count limits before persistence. Reserve quota atomically so concurrent requests cannot exceed it. Add rate limits and a cleanup policy for abandoned uploads, with monitoring for storage pressure.
- ASVS: [`v5.0.0-V2.4.1`](https://github.com/OWASP/ASVS/blob/v5.0.0/5.0/en/0x11-V2-Validation-and-Business-Logic.md) — anti-automation controls for excessive calls that can cause quota exhaustion or denial of service; [`v5.0.0-V5.2.4`](https://github.com/OWASP/ASVS/blob/v5.0.0/5.0/en/0x14-V5-File-Handling.md) — per-user file size and file-count quotas; [`v5.0.0-V15.2.2`](https://github.com/OWASP/ASVS/blob/v5.0.0/5.0/en/0x24-V15-Secure-Coding-and-Architecture.md) — defenses against availability loss from resource-demanding functionality.
