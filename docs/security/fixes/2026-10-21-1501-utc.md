### HIVE-SEC-2026-002 — Concurrent uploads can exhaust API memory before quotas run

- Status: **Change made, verification pending**.
- Changes: Added in-process upload admission before Express's raw body parser. It allows at most one active upload per authenticated user and two active uploads per API process; excess requests receive HTTP 429 with `Retry-After: 1`. Admission is released when the response finishes or when an incomplete request is aborted/closed.
